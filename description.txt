<h3>1. Project Overview & Objectives</h3>
<p>
  The SAR4Road dashboard provides interactive InSAR time-series analysis for road and infrastructure displacement monitoring across national roads in Japan.
</p>

<h3>2. InSAR Processing Methodology</h3>
<p>
  The ground subsidence information processed by a remote sensing technique called Interferometric Synthetic Aperture Radar (InSAR). Sentinel-1 SAR data were processed by using the open-source software packages ISCE and MintPy. Tropospheric delay was corrected by the APS model called ERA5 (the fifth generation of European Center for Medium-Range Weather Forecasts Reanalysis). SAR images are multi-looked to achieve a spatial resolution of around 30x30m in azimuth and range direction. SAR images from Descending tracks are used in the analysis.
</p>
<p>
  This represents a preliminary result, in which the ground displacement values are expressed as relative measurements with respect to a stable reference point within each study area, displayed as blue stars (★) on the map interface. Although the accuracy of the displacement data has been refined using appropriate tropospheric corrections, inter-area displacement adjustments have not yet been applied and displacement has not been calibrated with GNSS yet. These adjustments are planned for future implementation.
</p>

<h3>3. Dashboard Features</h3>
<p>
  Selecting a point on the map allows users to view time-series data and ground displacement velocity in <strong>'mm/year'</strong> unit.
</p>
<p>
  The displacement shown in red (negative value) indicates that the ground moved away from the satellite along the LOS direction. In contrast, the blue (positive value) indicates that the ground moved closer to the satellite.
</p>
<ul>
  <li><strong>Data Export:</strong> While viewing the time-series plot, users can export the data in .csv or .json format. Each layer file includes a legend displayed below it, serving as a visual guide to the color scheme.</li>
  <li><strong>Coordinate Search:</strong> Enter "Lat, Lon" or tap 🎯 for GPS location.</li>
</ul>
